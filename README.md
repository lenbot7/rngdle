# RNGdle Unlimited

RNGdle Unlimited is a fully visual clone of RNGdle with unlimited rolls per day. Roll a random number between 0 and 1,000,000, earn badges based on number patterns, and collect entropy points (EP).

## Features

- Unlimited rolls (no daily lockout)
- Badge cabinet with all badges in this clone
- Entropy point scoring and local leaderboard
- Roll history, stats, and shareable results

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
